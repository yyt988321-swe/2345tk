ImageStudio

Windows 图片编辑桌面软件及配套管理平台。

项目组成

* apps/desktop：Windows 桌面客户端
* apps/admin：Web 管理后台
* services/api：Node.js 后端 API
* packages/shared：共享代码
* docs：项目文档
* scripts：构建与发布脚本

开发计划

1. 建立统一工程结构
2. 开发 Windows 图片编辑客户端
3. 开发 Web 管理后台
4. 开发 Node.js 后端 API
5. 配置自动构建 Windows EXE

当前暂不开发 H5、Android、iOS 客户端及视频制作功能。
